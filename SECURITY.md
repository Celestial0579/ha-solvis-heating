# Security Policy

## Supported versions

Security fixes are provided for the latest release (see [Releases](https://github.com/Celestial0579/ha-solvis-heating/releases/latest)). Older versions are not maintained.

## Reporting a vulnerability

Please report vulnerabilities **confidentially** through the repository's Security tab: [Report a vulnerability](https://github.com/Celestial0579/ha-solvis-heating/security/advisories/new).

Do **not** open a public issue, and do not post details in discussions or pull requests.

## What to include

- affected version
- steps to reproduce
- impact (what can an attacker achieve?)

## What happens next

The report is reviewed. If the vulnerability is confirmed, a fixed version is published and announced through a release and a security advisory.

## Upstream code

This repository is a fork of [Lurchi70/ha-solvis-heating](https://github.com/Lurchi70/ha-solvis-heating). Vulnerabilities in code that comes from upstream and is unchanged here should be reported to the upstream repository. Report here only what affects the changes made in this fork.
